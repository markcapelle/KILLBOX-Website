Website Goal
The goal of the website is to showcase a game concept I built and demonstrate using Javascript to create engaging and responsive interaction with the user. The entire site is built using HTML5, CSS and Javascript.
In addition to the game itself, I’m also using a Javascript ‘loader’ that inserts the dedicated HTML pages for the banner, navigation and footer. The goal is to create a modular foundation so that should the project, or future projects, grow exponentially, all of the changes to the banner, navigation and/or footer can be done in one place and roll out automatically across the entire site.
